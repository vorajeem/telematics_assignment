# telematics_assignment
## Telematics ingestion and reporting (C++/SQL/Cross-platform)


This README.md provides brief instructions instructions on how to run the telematics application

## Instructions to run 

```
cd build/
cmake ..
cmake --build .
./telematics ../data/input_data.json
```
In general, the command to run the program can be: `./telematics [location_of_json_file]`
where `[location_of_json_file]` is the location of a JSON file.

## Testing data ingestion and storage (Manually)

Run: 
`./telematics ../data/duplicate_out-of-order_data.json`
